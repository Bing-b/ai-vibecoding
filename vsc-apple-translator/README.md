# AuraTranslate: AI 灵动翻译

一款为开发者设计的跨时代 AI 划词翻译插件，融合了 **极简苹果美学** 与 **DeepSeek 大模型** 的强悍性能。

## 核心亮点

- 🍎 **苹果美学设计**：精心设计的侧边栏 UI，包含毛玻璃效果 (Glassmorphism)、平滑微动画和优雅的排版。
- 🤖 **大模型支持**：连接 SiliconFlow API (如 DeepSeek, ChatGLM 等)，提供更懂上下文的翻译。
- 🐫 **开发者友好**：中翻英时自动转换为 **小驼峰 (camelCase)** 格式，方便直接作为变量名使用。
- 🔄 **智能互译**：自动识别语种，支持中英双向互译。
- ⚡ **快速集成**：支持划词后右键菜单一键翻译，并提供“替换原文”和“复制结果”快捷操作。

## 使用指南

1. **配置密钥**：
   - 打开设置 (`Ctrl + ,`)。
   - 搜索 `翻译`。
   - 在 `API 密钥` 框中输入您的 [SiliconFlow API Key](https://cloud.siliconflow.cn/)。
   - _提示：代码中已内置了一个演示用的 Key，您也可以直接开始体验。_
2. **划词翻译**：
   - 在代码中选中一段文本。
   - **右键**点击，选择 `大模型翻译`。
   - 翻译结果将即时显示在左侧的“翻译”面板中。
3. **操作结果**：
   - 点击 **“替换原文”**：直接将代码中的选中文字替换为翻译结果。
   - 点击 **“复制结果”**：将结果存入剪贴板。

