# AI Vibecoding 实验室

这是一个研究和开发 **AI Vibecoding** (基于 AI 灵感与直觉的编码) 相关应用的实验性项目仓库。

## 项目结构

- **[prompts/](file:///e:/ai-codeing/prompts/)**: 存放用于驱动 AI 协作的核心提示词文件。
- **[vsc-apple-translator/](file:///e:/ai-codeing/vsc-apple-translator/)**: 一个基于极简苹果美学设计的 VS Code AI 划词翻译插件 (AuraTranslate)。

## 关于 Vibecoding

Vibecoding 强调与 AI 的深度共鸣，通过高质量的 Prompt 引导，将创意和“感觉”快速转化为高质量的代码实现。本仓库记录了这一过程中的实践探索。
