# 角色定义

你是一个经验丰富的 VS Code 插件开发专家，精通 TypeScript、VS Code Extension API（如 HoverProvider, Webview 等）以及现代化的 UI/UX 设计。

# 任务目标

请帮我开发一个完整的 VS Code 翻译插件。该插件的核心功能是：用户在编辑器中选中文本后，使用基于大模型（LLM）的 API 进行翻译，并在选中文本处自动弹出精致的 UI 面板显示结果。

# 核心功能需求

1. **划词自动翻译**：监听用户在编辑器中的文本选中事件（或通过快捷键触发），以浮窗（Hover）或 Webview 的形式在旁边弹出翻译结果。
2. **智能中英互译**：
   - 自动检测语言：中文翻译为英文，英文翻译为中文。
   - **代码变量友好**：当中文翻译为英文时，**默认自动将其转换为小驼峰（camelCase）风格**，以便直接作为变量名使用。
3. **快捷替换/复制**：在翻译结果面板中提供交互按钮，支持一键将源代码选中文本**替换**为翻译结果，或一键**复制**。
4. **大模型 API 集成**：使用特定的 LLM 接口完成高质量翻译。
   - **API 地址**: `https://api.siliconflow.cn/v1/chat/completions` (OpenAI 格式)
   - **API Key**: 请在代码中预留配置项或明显的常量占位符（如 `YOUR_API_KEY_HERE`），待我后续自己填充。
   - **System Prompt**: 请在代码中内置一个优秀的系统提示词（System Prompt），要求大模型充当顶级程序员翻译官，并强制输出指定格式（如纯文本的小驼峰命名等）。

# UI/UX 设计要求 (Apple 风格)

UI 交互风格需要参考苹果软件产品（如 macOS/iOS 的设计语言）：

1. **毛玻璃质感 (Glassmorphism)**：如果使用 Webview，请实现半透明的磨砂背景模糊效果（`backdrop-filter: blur`）。
2. **圆角与投影**：弹窗边缘采用柔和的圆角（如 `12px`），并搭配自然、有层次感的弥散阴影，使其在代码上方有浮动感。
3. **极简排版**：字体排布清晰优雅，支持浅色/深色主题（随 VS Code 主题自动切换），使用充满科技感的无衬线字体。
4. **平滑动画**：面板弹出、加载中（Loading）状态、以及按钮 Hover 时，需要有顺滑的过渡微动画。
